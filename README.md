# Tiny Swords: Kingdom Defense

A bilingual tower-defense game built with Godot 4.7 and the Tiny Swords free asset pack.

使用 Godot 4.7 制作的中英双语塔防游戏，采用 Tiny Swords 免费素材包。

## Features / 游戏功能

- Random full-screen maps / 随机全屏地图
- Archer, cannon, frost, barricade and gold-mine towers / 多种防御塔与矿塔
- Buildable foundations / 自由建造地基
- 10 waves with bosses on waves 5 and 10 / 10 个波次，第 5、10 波出现 BOSS
- Tower upgrades and selling / 防御塔升级与出售
- Chinese and English interface / 中英文界面切换

## Run / 运行

Open `project.godot` with Godot 4.7, then press `F5`.

使用 Godot 4.7 打开 `project.godot`，然后按 `F5`。
